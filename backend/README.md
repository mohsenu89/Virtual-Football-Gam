# Virtual Football Online backend

هذا مجلد خادم المباريات الأونلاين. الواجهة الحالية على GitHub Pages تبقى كما هي، وتُضاف صفحة منفصلة `online.html`.

## المكونات
- Cloudflare Worker: API والتحقق من جلسات الزوار والرهانات.
- D1: المستخدمون والمحافظ والفرق وجدول المباريات والرهانات والأحداث.
- Durable Objects + WebSocket + Alarms: محرك حالة مركزي لكل مباراة، حتى يشاهد كل المستخدمين نفس النتيجة والوقت.

## إعداد Cloudflare
1. أنشئ D1 database باسم `virtual-football-db`.
2. انسخ قيمة Database ID إلى `database_id` في `wrangler.toml`.
3. من مجلد `backend` نفّذ:
   `npx wrangler d1 migrations apply virtual-football-db --remote`
4. اضبط سر جلسات الزوار:
   `npx wrangler secret put GUEST_SECRET`
   واكتب قيمة طويلة وعشوائية عند الطلب.
5. انشر:
   `npx wrangler deploy`
6. بعد النشر، انسخ عنوان Worker إلى `online-config.js` في جذر المشروع مكان العنوان التجريبي.
7. تأكد من أن GitHub Pages يعرض آخر نسخة من المستودع.

## التطوير والاختبار
- `npx wrangler dev`
- `npx wrangler tail`
- `curl https://YOUR-WORKER.workers.dev/api/health`

## الجدول
المجدول ينشئ مباريات اليوم واليومين التاليين تلقائياً. الدوري يتكون من 10 فرق، 9 جولات، و5 مباريات في اليوم، بمواعيد UTC متفرقة (08:00، 11:00، 14:00، 17:00، 20:00). كل مباراة 180 ثانية فعلية، مع عداد 0–90.

## قواعد الرهان
- رصيد تجريبي ابتدائي: 1000 نقطة.
- حد الرهان: 1 إلى 500 نقطة.
- رهان واحد لكل زائر في كل مباراة.
- تُغلق الرهانات عند وقت انطلاق المباراة.
- التسوية تتم في الخادم فقط، والمكسب يعاد إلى المحفظة التجريبية.
- لا توجد عمليات إيداع أو سحب أو تحويل لأموال حقيقية.

## ملاحظات مهمة قبل الإطلاق العام
هذا إصدار تأسيسي يحتاج اختبار ضغط وأمان ومراجعة حدود Cloudflare. أسماء الزوار جلسات مجهولة مرتبطة بهذا المتصفح؛ مسح بيانات المتصفح يفقد الجلسة. محرك التحريك الأونلاين في هذه النسخة مستقل عن محاكاة الصفحة الفردية ويستخدم حركة تكتيكية مبسطة وأحداث أهداف محددة مركزياً؛ لا يغيّر كود المحاكاة الفردية.
